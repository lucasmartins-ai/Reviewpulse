# Roadmap

## Portfolio Release

- Keep the app runnable with no credentials.
- Use SQLite for local persistence.
- Keep pages visible and easy to review.
- Document setup and quality commands clearly.
- Keep security basics explicit.
- Include README screenshots for the dashboard and public feedback form.

## Near-Term Improvements

- Add a reset button for the local SQLite demo data.
- Add one more Playwright flow for CSV download.
- Add simple trend visualization from SQLite rows.

## Out of Scope

- Production auth.
- Hosted database provisioning.
- Payment plans.
- External LLM provider setup.
- Multi-tenant admin workflows.
