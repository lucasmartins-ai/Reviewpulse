## 📌 Overview

ReviewPulse is a portfolio-ready local feedback operations platform that helps businesses aggregate, analyze, score, and respond to customer reviews.

Engineered with a **local-first architecture**, ReviewPulse requires **zero external API keys or cloud database setups** to run locally.

---

## 🚀 Key Features

- **Feedback Ingestion & Sentiment Scoring:** Normalizes customer reviews and extracts satisfaction metrics.
- **Local SQLite Contract:** Portable relational schema with test seed fixtures.
- **Robust Validation:** Full Zod schema validation across all inputs and API routes.
- **Comprehensive Test Suite:** Unit and integration tests with Vitest and end-to-end flows with Playwright.

## 📦 Quick Start

```bash
# Clone repository
git clone https://github.com/lucasmartins-ai/Reviewpulse.git
cd Reviewpulse

# Install dependencies
npm install

# Run local development server
npm run dev
```

## 🧪 Testing

npm run test

# Run E2E test suite
npm run test:e2e
